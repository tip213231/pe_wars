# pe_wars

Клиентский NeoForge мод и серверный Bukkit/Paper плагин — аддон к Towny, добавляющий систему рейдов и войн. Стиль меню повторяет `pe_townymenu`.

## Состав проекта

- `client-neoforge` — клиентский мод Minecraft 1.21.1 NeoForge. Меню войн/рейдов на клавишу **H** + обработка команд `/t war`, `/t raid`.
- `server-plugin` — серверный плагин для Paper/Spigot/Youer. Вся боевая логика, интеграция с Towny и Vault.

Архитектура — та же, что у `pe_townymenu`: клиент и сервер общаются через чат-маркеры `[PETM_WAR]` / `[PETM_RAID]`. Towny используется **только через рефлексию** (без compile-зависимости), Vault — для экономики.

## Сборка

```bat
gradlew.bat build
```

После сборки:
- `client-neoforge/build/libs/pe_wars-neoforge-1.21.1-1.0.0.jar` — ставится игрокам в `mods`.
- `server-plugin/build/libs/pe_wars-server-1.0.0.jar` — ставится на сервер в `plugins`.

## Установка

1. На сервере должны быть: **Towny** и **Vault** (+ любой economy-плагин, например EssentialsX/CMI Economy).
2. Положить `pe_wars-server-*.jar` в `plugins/`, перезапустить сервер.
3. Настроить `plugins/pe_wars/config.yml` (цены, длительности фаз, списки материалов).
4. Игрокам поставить `pe_wars-neoforge-*.jar` в `mods` (опционально — меню работает и из обычного чата через команды).
5. Рекомендуется также `pe_townymenu` — там добавлена кнопка «⚔ Войны / Рейды» на главную страницу.

## Команды

| Команда | Описание |
|---|---|
| `/t war` | открыть меню войн (если установлен клиентский мод) |
| `/t raid` | открыть меню рейдов |
| `/pewar` | алиас меню войн |
| `/peraid` | алиас меню рейдов |
| `/pewar declare <город>` | быстро объявить войну городу |
| `/peraid declare <город>` | быстро объявить рейд городу |
| `/pewar action <действие> [аргумент]` | действие из GUI (base64-url аргумент) |
| `/pewar reload` | перезагрузка конфига (права `pewars.admin`) |

## Механики

### 💥 Рейд (1000 монет с банка города)
- **Подготовка (15 мин):** PvP off, ломать и строить запрещено.
- **Активная фаза (15 мин):** PvP on, разрешено ломать двери/люки/стекло (дропаются), остальное защищено. Строительство гражданам города-защитника запрещено.
- **Завершение:** по истечению активной фазы ИЛИ если в зоне нет атакующих (60 сек по умолчанию).

### ⚔ Война (25000 монет с банка нации)
- **Подготовка (60 мин):** нельзя менять спавн, кикать/принимать игроков, использовать банк города/нации, телепортироваться в мирные зоны/центральные чанки.
- **Активная фаза (120 мин):** полный PvP, захват чанков.
  - Обычный чанк: нужен 80% контроля (атакующих больше, чем защитников, прогресс копится).
  - Центральный чанк (= homeblock города): нужно 40% онлайна атакующей нации физически в нём. Его захват = мгновенная победа.
- **Завершение войны:**
  - Захвачен центральный чанк → атакующие побеждают.
  - Истекла активная фаза без захвата центра → защитники удержались.
  - Нет атакующих в зоне 15 минут → атака прекращена.
- **Захват чанков:** во время войны — виртуальный (атакующие получают PvP-права). При победе атакующих захваченные чанки реально переходят им через Towny API; при поражении — полностью возвращаются защитнику.

### Конфиг
Все цены, длительности фаз, списки ломаемых блоков и запрещённых при войне команд — в `plugins/pe_wars/config.yml`.

## Права

- `pewars.use` (default: true) — пользоваться командами.
- `pewars.admin` (default: op) — объявлять войны/рейды без проверки ролей, перезагрузка конфига.

## Замечания

- Обращения к Towny идут через рефлексию (как в `pe_townymenu`), поэтому плагин не требует compileOnly-зависимости и деградирует аккуратно, если Towny/Vault отсутствуют.
- Принудительный PvP в зонах рейда/войны реализован через `EntityDamageByEntityEvent` (EventPriority.HIGHEST): если Towny отменил урон из-за PvP-off, плагин переоткрывает его для участников.
- Реальный захват чанков при победе идёт через `TownBlock.setTown(...)` (с fallback на `TownyUniverse.removeTownBlock` + claim командой).
